# whydou

A small German article quiz: paste a text and fill in the missing *der*, *die* and *das*.

## Stack

React 19 · TypeScript · Vite · TanStack Router (file-based routes) · Tailwind CSS 4 · Zustand · class-variance-authority · oxlint · Prettier

## Development

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # typecheck + production build into dist/
npm run lint
npm run format:check
npm test             # tokenizer, scoring and the sample explanations
```

`src/routeTree.gen.ts` is generated by the router plugin when Vite runs; commit it when routes change.

## Explanations

After checking, every wrong article is explained: the noun, its gender and case, what the typed answer would have meant, and the grammar rules behind it. The explanations for the built-in texts are written by hand in `src/lib/samples.ts` (one entry per article, in reading order) and the rules live in `src/lib/grammar.ts`. `npm test` fails if a text and its explanations drift apart, so edit them together.
