# whydou

A small German article quiz: paste a text and fill in the missing *der*, *die* and *das*.

## Stack

React 19 · TypeScript · Vite · TanStack Router (file-based routes) · Tailwind CSS 4 · Zustand · class-variance-authority · oxlint · Prettier

## Development

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # typecheck + production build into dist/
npm run lint
npm run format:check
```

`src/routeTree.gen.ts` is generated by the router plugin when Vite runs; commit it when routes change.

## Deployment

Pushes to `main` are built and published to GitHub Pages by `.github/workflows/deploy.yml` (served from `/whydou/`). One-time setup: repo **Settings → Pages → Source: GitHub Actions**.

## Data

Noun genders in `src/lib/nouns.json` are generated by `scripts/build-nouns.mjs` from the German Wiktionary, via the [kaikki.org](https://kaikki.org/) Wiktextract dump. Wiktionary content is available under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) and GFDL; the generated list is shared under the same license. It is bundled as a static file, with no runtime network lookups.
