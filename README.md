# whydou

A small German article quiz: paste a text and fill in the missing *der*, *die* and *das*.

## Stack

React 19 · TypeScript · Vite · TanStack Router (file-based routes) · Tailwind CSS 4 · Zustand · class-variance-authority · oxlint · Prettier

## Development

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # typecheck + production build into dist/
npm run lint
npm run format:check
```

`src/routeTree.gen.ts` is generated by the router plugin when Vite runs; commit it when routes change.

## Personalized explanations (experimental)

The wrong-answer popover has an opt-in **personalize** button. It downloads a small 4-bit model ([Qwen2.5-0.5B-Instruct](https://huggingface.co/onnx-community/Qwen2.5-0.5B-Instruct), about 500 MB, cached by the browser) from Hugging Face and runs it with [transformers.js](https://huggingface.co/docs/transformers.js) on WebGPU. The rule-based analyzer in `src/lib/analyze.ts` stays the source of truth: the model only gets its facts and rephrases them for the learner's sentence (`src/lib/personalize.ts`). Without WebGPU the button says so and the plain explanation stays.

## Deployment

Pushes to `main` are built and published to GitHub Pages by `.github/workflows/deploy.yml` (served from `/whydou/`). One-time setup: repo **Settings → Pages → Source: GitHub Actions**.
