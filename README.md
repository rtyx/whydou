# whydou

A small German article quiz: paste a text and fill in the missing *der*, *die* and *das*.

## Stack

React 19 · TypeScript · Vite · TanStack Router (file-based routes) · Tailwind CSS 4 · Zustand · class-variance-authority · oxlint · Prettier

## Development

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # typecheck + production build into dist/
npm run lint
npm run format:check
```

`src/routeTree.gen.ts` is generated by the router plugin when Vite runs; commit it when routes change.

## Personalized explanations (experimental)

On capable desktops (a real WebGPU adapter, 8 GB+ memory where the browser reports it, no data saver or slow connection) the app quietly downloads a small 4-bit model ([Qwen2.5-0.5B-Instruct](https://huggingface.co/onnx-community/Qwen2.5-0.5B-Instruct), about 500 MB, cached by the browser) from Hugging Face while the learner fills in the gaps, and runs it with [transformers.js](https://huggingface.co/docs/transformers.js). After checking, it rephrases the explanation of each wrong answer for its sentence; the popover shows the rule-based text until the rephrased one is ready. The rule-based analyzer in `src/lib/analyze.ts` stays the source of truth: the model only gets its facts and rephrases them (`src/lib/personalize.ts`). Every other client keeps the plain explanation. While the model is in use, an **AI** chip in the header shows its state (loading with progress, rephrasing, on, or unavailable), and rephrased explanations are marked "✦ rephrased by on-device AI" in the popover. Clients that cannot run the model see neither.

## Deployment

Pushes to `main` are built and published to GitHub Pages by `.github/workflows/deploy.yml` (served from `/whydou/`). One-time setup: repo **Settings → Pages → Source: GitHub Actions**.
